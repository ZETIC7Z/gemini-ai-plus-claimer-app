## 📖 Overview

**ZETICUZ AI PLUS GEN** is an independent, high-performance, client-side automation portal and native Windows utility engineered to streamline promotional student gateway verification and provision official 12-Month Google AI Plus redemption links (including **Gemini Advanced** and **2TB Google One cloud storage**).

Unlike generic scripts, this project features a **custom 3D WebGL motion landing page**, an **overhauled modern 3D glossy desktop application**, and a **hardened Playwright automation engine** that executes 100% locally on your machine with zero remote tracking or external telemetry.

## 🚀 Quickstart & Usage

### Method 1: Download Pre-Built Executable (Fastest)

1. Download **`Zeticuz AI Plus Gen.exe`** from the [Latest Release](https://github.com/ZETIC7Z/gemini-ai-plus-claimer-app/releases/latest) or directly from the [Live Web Hub](https://gemini-ai-plus-claimer.vercel.app/).
2. Run the executable on Windows 10 or 11 (No Python installation required).
3. Enter your Gmail address in the control panel.
4. Click **`⚡ Get 1-Year Access Link`**.
5. When prompted, enter the 6-digit confirmation OTP sent to your Gmail inbox.
6. Check your email or use the in-app button to activate your 12-Month Google AI Plus membership!

### Method 2: Run From Source (Developers)

```bash
# 1. Clone the repository
git clone https://github.com/ZETIC7Z/gemini-ai-plus-claimer-app.git
cd gemini-ai-plus-claimer-app

# 2. Install dependencies
pip install -r app/requirements.txt
playwright install chromium

# 3. Launch the desktop GUI
python app/zeticuz_ai_plus_gen.py
```

### Method 3: Compile Standalone `.exe` Locally

```bash
# Run the automated build script:
python scripts/build_exe.py

# Standalone binary will be generated at:
# dist/Zeticuz AI Plus Gen.exe
```
